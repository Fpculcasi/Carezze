**Assumption:** First scheduled dose of a medication is at 08:00 unless overridden. Times are generated by spacing `frequencyHours` apart within a 24h window, cycling back if they exceed midnight.

## Algorithm
Given `frequencyHours` and optional `startHour: Int = 8`:
- `dosesPerDay = 24 / frequencyHours` (if 24 % frequencyHours == 0, else round to nearest sensible interval)
- For each dose index `i in 0 until dosesPerDay`: time = `(startHour + i * frequencyHours) % 24` formatted as "HH:mm"
- Edge case: `frequencyHours >= 24` → single dose per day at startHour → `["08:00"]`
- Edge case: `frequencyHours == 0` → guard against division by zero

## Pre-mortem (Standard)
1. Non-divisible `frequencyHours` (e.g. 7h in 24h) — produces fractional doses. Mitigation: compute `floor(24 / frequencyHours)` and space evenly.
2. Off-by-one in hour formatting → `"8:00"` instead of `"08:00"`. Mitigation: use `String.format("%02d:%02d", h, 0)`.
